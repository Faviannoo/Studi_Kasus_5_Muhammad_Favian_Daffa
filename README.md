1. Function Menghitung Biaya Kamar

<img width="300" height="128" alt="image" src="https://github.com/user-attachments/assets/4e9f6691-9da0-4bc4-bb2a-3ab8171dbc62" />

Bagian ini berfungsi untuk menghitung total biaya menginap berdasarkan jenis kamar dan lama menginap. Fungsi hitung_biaya() menerima dua parameter, yaitu jenis_kamar dan lama_menginap<br>

Jika jenis kamar yang dipilih adalah Standard, maka tarifnya sebesar Rp200.000 per malam. Jika memilih kamar Deluxe, tarifnya sebesar Rp350.000 per malam. Selanjutnya, tarif dikalikan dengan jumlah malam menginap dan hasilnya disimpan dalam variabel biaya. Perintah return biaya digunakan untuk mengembalikan hasil perhitungan tersebut<br>
